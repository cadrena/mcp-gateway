# MCP Gateway

## Status

Pre-V1 design and implementation.

This repository is the public home for the design and future implementation of an MCP gateway. It does not yet contain a runtime implementation.

## Roadmap

The initial V1 direction is to target Streamable HTTP. The project may integrate with the public `github.com/cadrena/policy-engine` module after that project has its first tagged release; Batch 0 adds no such dependency.
